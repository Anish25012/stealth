Principles

  • {{ icon("shield-check") }}

    Answer the question first

    Every screen opens with "am I protected, and is there anything I need to do?"

  • {{ icon("sparkles") }}

    Calm, not loud

    One accent, lots of space, colour only where it means something.

  • {{ icon("lock") }}

    Private by design

    Every asset ships with the app. No fonts, icons or scripts from the internet.

  • {{ icon("user") }}

    Plain words

    Short sentences. Status badges always carry words, never colour alone.
